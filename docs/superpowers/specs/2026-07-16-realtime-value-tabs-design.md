# 采集值与调度值实时刷新设计

日期：2026-07-16

## 目标

第 6 页始终显示采集侧领域点的当前值；第 7 页始终显示从 Java 调度子站收到的当前值。两个页面随运行时事件刷新，不要求重新发起总召或切换页签。

## 状态边界

- `collect_values` 继续作为采集侧唯一当前值，由点值手工修改、主动上送前刷新、控制执行提交和点表重载触发更新。
- 新增独立的调度当前值状态，按遥信/遥测与电度分区保存。
- `dispatch_general`、`dispatch_energy` 继续保存最近一次完整总召快照，仅在对应召唤收到完整匹配的 ACTTERM 后原子替换。
- 调度当前值接收支持协议层已解析的遥信、遥测、电度和 SOE。总召数据和主动变化上送都立即逐点合并。
- `M_SP_TB_1` 与 `M_SP_NA_1`、`M_DP_TB_1` 与 `M_DP_NA_1` 视为同一当前值类型族，SOE 更新原有遥信行，不生成重复点。
- CA 不匹配、Test 位或 Negative 位的测量报文不进入当前值。

## 事件流

调度协议任务收到合格测量 ASDU 后，转换为 `PointView` 并发布当前值事件。运行时协调器按 IOA 和兼容类型族合并到调度当前值，再通过现有 `watch` 快照通知 TUI。完整总召事务同时沿用原有累积及原子提交路径。

## 界面

- 第 6 页标题改为“采集当前值 · 实时刷新 · 单击点位修改”。
- 第 7 页上区显示“调度当前遥信/遥测 · 实时刷新”，下区显示“调度当前电度 · 实时刷新”。
- 表格继续显示 IOA、名称、类型、值、品质和更新时间。

## 滚轮导航

- 第 6 页维护一个采集当前值滚动位置，鼠标滚轮向下显示后续点位，向上返回前序点位。
- 第 7 页为上方遥信/遥测和下方电度分别维护滚动位置；只滚动鼠标当前所在的表格。
- 每个滚动位置按表格实际可见行数和当前点位数量限制，窗口缩放或点表重载后不会出现整页空白。
- 切换页签时保留各值表位置。第 6 页单击编辑点位时把滚动位置计入行号，保证编辑对象与屏幕点击行一致。

## 验证

按用户要求不采用 TDD。实现后增加回归测试，覆盖无总召轮次的主动上送、SOE 类型族合并、完整总召快照与当前值隔离、采集值滚动、调度上下表独立滚动及滚动后的采集点点击映射；最后运行全量测试、`cargo fmt --check` 和严格 Clippy。
